# TendiTudo
 TendiTudo é um armazem de material de construção no qual foi solicitado um programa para facilitar a indentifucação de seus produtos e controlar seu estoque de forma pratica e satisfatória. Nossa equipe se encarregou no desenvolvimento do programa

**⁠Quem é o público alvo**

Pessoas interessadas em matérias de construção de qualidade e empresa que quer controlar o estoque dos produtos que são vendidos 

**Problema que a solução pretende resolver** 

Resolver a alta demanda, controlar  seus matérias e identificar produtos em seu estoque
